# 插件与 Pro

ImgNest 核心带一个进程内插件接口;付费的 ImgNest Pro 在其上提供单点登录等企业功能,不影响免费版的任何行为。

## 插件系统能做什么

插件编译进二进制,挂在 `/api/ext/{name}` 下,核心给它们的能力包括:

| 钩子 | 用途 |
| --- | --- |
| 登录提供方 | 在登录页追加第三方登录按钮,由插件完成身份验证后走核心的账号绑定 |
| 访问守卫 | 对公开图片路由(`/i/...`、缩略图、画廊)做自定义放行 / 拦截 |
| 事件 | 订阅上传、删除等站点事件做同步处理 |
| 展示变换 | 在对外展示的 WebP 上叠加水印等 |

每个插件的路由相互隔离,不能遮蔽核心路由或彼此遮蔽;插件名只允许 `[a-z0-9-]`。插件设置卡片出现在后台「系统设置 → 插件」。

目前插件随 Pro 发行版提供;核心仓库的 `extension/extension.go` 是接口的权威定义。

## ImgNest Pro

Pro 是独立仓库 [imgnest-pro](https://github.com/biliblihuorong/imgnest-pro),以钉死版本的核心构建,新增:

- **SSO 单点登录**:通用 OIDC(Keycloak、Authentik、Casdoor 等)、GitHub、Google 预设;PKCE + nonce 全程校验,状态绑定浏览器,按客户端限流。
- **授权机制**:Ed25519 离线验签的授权码,按"更新期"决定哪些构建可用;没有授权码或验签失败时,付费功能整体关闭,其余行为与免费版完全一致。

### SSO 的邮箱绑定开关

`link_by_email` 允许首次登录时把**已验证邮箱**与本站同邮箱的普通账号直接绑定。只对你信任其邮箱声明的身份提供方打开;管理员账号永远不会被自动绑定。

## 授权与构建(面向运营者)

- `licensetool keygen` 生成签名密钥对;私钥只留在签发机器,构建时只注入公钥。
- 不注入公钥的构建不接受任何授权码,天然 fail-closed。
- Pro 配置与核心配置是两个文件(`IMGNEST_PRO_CONFIG` 指向),Pro 的密钥不会进入免费版的配置面。
