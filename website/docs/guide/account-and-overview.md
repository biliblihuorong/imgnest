# 账户与用量

## 修改资料和密码

- 两种布局都是：侧栏「账户」→「资料与安全」（`/account/settings`）。经典布局的右上角用户菜单里也有「账户」。
- 在资料区修改「显示名称」，点「保存资料」。留空时对外显示用户名；邮箱、用户名和头像来源不是这张表单的可编辑项。
- 在「账户安全」填写当前密码、新密码与确认密码，点「修改密码」。成功后需要重新登录，该账号原有浏览器会话和 API Token 都失效，PicGo 等客户端也需要重新配置 Token。
- API Token 的创建与吊销在「账户 → API Token」（`/account/tokens`），步骤见[蓝空 API 与 PicGo](./lsky-api.md#获取-token)。

## 个人水印

使用已授权的 Pro 时，侧栏「账户」里有独立的「我的水印」标签（`/account/plugins/watermark`）。在这里选择组默认、个人文字、个人 Logo 或不使用水印，并保存设置。上传 Logo 后仍需选择 Logo 模式并保存。

Free 组默认由管理员统一控制，该页面显示组策略说明；只有允许个人设置的组能编辑。水印只影响之后上传时生成的静态 WebP 展示版，不改原图、缩略图或历史图片。普通版、未授权或当前不可用的功能不会显示额外标签。

## 查看自己的用量与登录活动

导航「数据概览」（`/dashboard`）显示当前账号的图片、相册和存储用量；下方「账户活动」显示最近登录、有效会话与 API 调用情况。点「刷新数据」重新读取，失败的卡片可以重试。

「回收站」数量不等于已用容量：进入回收站后用户额度释放，但文件仍在存储中，见[隐私与回收站](./privacy-and-trash.md#回收站)。API 调用按 UTC 日期统计，最近一分钟可能尚未计入。

## 管理员查看全站

管理员进入「站点管理 → 站点概览」（`/admin/overview`）查看全站统计；在「用户管理」对应用户的「详情」中查看该用户活动。「全站图片」（`/admin/images`）管理所有用户图片；普通用户没有这些入口。

## 扩展插件在哪里

管理员进入「站点管理 → 站点设置 → 插件」（`/admin/settings/plugins`）。只有当前运行程序已装配且提供配置的插件才会出现；页面显示空状态时，代表没有可配置插件，无法从这里安装插件。插件的构建接入属于开发流程，见仓库的扩展说明。
