# 用户与用户组

这一页面向管理员。用户组决定一个账号可以上传到哪里、传多大、传多少；它不决定图片是否公开。

## 从哪里打开

管理员登录后进入「站点管理」：

- 「用户组」（`/admin/groups`）→「新建用户组」或已有组的「编辑」→ 配置限制与规则 → 保存。
- 「用户管理」（`/admin/users`）→「新建用户」或已有用户的「编辑」→ 设置所属组等资料 → 保存。
- 普通账号看不到这些菜单。修改组后，用该组账号到「上传图片」检查可选规则与上传限制。

## 配置顺序

1. 在[存储与规则](./storage-and-policies.md)里创建并测试存储，再建上传规则。
2. 在「用户组」里绑定可用规则，选择默认规则，并配置容量、单文件大小、允许格式和上传频率。
3. 在「用户管理」里创建账号或调整所属组。管理员能查看全站图片，普通用户管理自己的图片。

用户组没有可用规则时，用户不能正常上传。默认规则需要属于该组的可用规则。

## 注册与游客分别用哪个组

| 使用者 | 配置位置 | 作用 |
| --- | --- | --- |
| 新注册账号 | 站点管理 → 站点设置 → 注册与登录 → 默认用户组 | 注册时分配给新用户 |
| 已有账号 | 用户管理 → 编辑用户 | 调整这个账号的组 |
| 未登录上传者 | 站点管理 → 站点设置 → 访客与画廊 → 游客用户组 | 游客上传使用的限制与规则 |

注册默认关闭；打开注册不会自动开放游客上传或画廊。邮箱验证、人机验证和找回密码见[登录保护](./sign-in-protection.md)，游客的可见性与入口见[访客与公开展示](./public-access.md)。

## 容量与停用

容量用量按保存到存储的原图、WebP、云缩略图和响应式文件计算，同一对象只算一次；本地缩略图缓存不计。进回收站后用户额度释放，但物理文件在保留期内仍占存储空间，恢复时需要重新满足容量限制。

停用用户会阻止其继续使用账号，其图片不再进入公开画廊；已经分享的图片直链仍按存储访问规则提供。要让图片源站地址失效，应通过图片删除流程处理，见[隐私与回收站](./privacy-and-trash.md)。
