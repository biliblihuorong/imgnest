# 界面与主题

ImgNest 的界面打包后嵌在程序里，不需要单独部署。它自带两种布局，可以在运行时切换，都支持深色模式和中英文。

## 两种布局

**新版布局**是默认的：

- 侧栏浮在页面上，可以收成只显示图标
- 按 `Ctrl K`（macOS 是 `⌘ K`）打开检索，搜图片或者跳转页面
- 宽屏下，「我的图片」右侧有详情面板，显示尺寸、大小和各种格式的链接

**经典布局**是顶栏加标签页的后台样式。

切换的位置：

- 新版布局里：侧栏底部的齿轮 → 设置 → 外观 → 布局
- 经典布局里：右上角用户菜单 → 切换到新版布局

切换立即生效，不需要重新构建，也不需要刷新页面。

## 外观设置

「设置 → 外观」里可以调整：

| 设置 | 选项 |
| --- | --- |
| 布局 | 新版、经典 |
| 深浅色 | 浅色、深色、跟随系统 |
| 强调色 | 几种预设颜色 |
| 圆角 | 小、中、大 |
| 紧凑侧栏 | 只显示图标 |
| 语言 | 中文、English |

没登录的访客也可以切换深浅色、语言和布局。

这些偏好保存在浏览器里，换一台设备需要重新设置。强调色和圆角在你没有自己选过时跟随当前布局的默认值；选过之后，两种布局共用你的选择。

## 开发界面

界面源码在仓库的 `web-vben/` 目录，用 Vue 3、Vite 和 Naive UI。命令都在开发镜像里执行：

```bash
make fe-build   # 构建界面
make fe-test    # 运行组件测试
make fe-lint    # 类型检查与代码检查
make release    # 构建界面并编译出 bin/imgnest
```

更多细节见仓库里的 [`docs/development.md`](https://github.com/biliblihuorong/imgnest/blob/main/docs/development.md)。
