# 界面与主题

ImgNest 的界面打包后嵌在程序里，不需要单独部署。它自带两种布局，可以在运行时切换，都支持深色模式和中英文。

## 两种布局

**新版布局**是默认的：

- 侧栏浮在页面上，可以收成只显示图标
- 按 `Ctrl K`（macOS 是 `⌘ K`）打开检索，搜图片或者跳转页面
- 宽屏下，「我的图片」右侧有详情面板，显示尺寸、大小和 EXIF；复制链接使用图片卡片右键菜单，见[上传与图片管理](./upload-and-images.md#管理已有图片)

**经典布局**是顶栏加标签页的后台样式。

切换的位置：

- 新版布局里：侧栏底部的齿轮 →「设置」→「布局」→ 选择新版或经典布局。
- 经典布局里：顶栏的齿轮，或右上角用户菜单 →「设置」→「布局」→ 选择新版或经典布局。用户菜单里的「切换到新版布局」也可以直接切换。

切换立即生效，不需要重新构建，也不需要刷新页面。

## 外观设置

两种布局打开的是同一个「设置」弹窗，直接显示以下选项：

| 设置 | 选项 |
| --- | --- |
| 布局 | 新版、经典 |
| 深浅色 | 浅色、深色、跟随系统 |
| 强调色 | 几种预设颜色 |
| 圆角 | 小、中、大 |
| 紧凑侧栏 | 只显示图标 |
| 语言 | 跟随浏览器、简体中文、English |

登录页提供深浅色和语言切换；登录后可在控制台调整布局等完整外观偏好。

资料、密码和 API Token 统一在「账户」页管理，不在设置弹窗内。登录后可以点弹窗底部的「打开账户」，再选「API Token」或「资料与安全」；具体步骤见[账户与用量](./account-and-overview.md)。

这些偏好保存在浏览器里，换一台设备需要重新设置。两种布局共用默认强调色和圆角；切换布局会保留当前选择。「恢复默认外观」只将强调色和圆角还原为这套共用默认值。

升级后，经典布局里仍使用旧默认强调色或圆角的选项会一次性改用共用默认值，其他自选值保留。之后可以重新选择旧经典蓝或中等圆角，刷新页面也会保留。

## 开发界面

界面源码在仓库的 `web-vben/` 目录，用 Vue 3、Vite 和 Naive UI。命令都在开发镜像里执行：

```bash
make fe-build   # 构建界面
make fe-test    # 运行组件测试
make fe-lint    # 类型检查与代码检查
make release    # 构建界面并编译出 bin/imgnest
```

更多细节见仓库里的 [`docs/development.md`](https://github.com/biliblihuorong/imgnest/blob/main/docs/development.md)。
