# 相册与画廊

相册用来整理自己的图片;画廊是站点对外的一扇窗,把公开图片以瀑布流展示给访客。

## 相册

- 登录后在「相册」页创建、改名、删除相册;删除相册不会删除图片,图片只是退出该相册回到「未分组」。
- 每个相册可以设置封面;相册详情页看到的永远是这个相册里的图,切换搜索词也不会越出范围。
- 上传时可以直接指定相册;已有图片用批量操作移动。
- 「未分组」是一个固定视图,代表不属于任何相册的图片,在搜索里对应 `album:unfiled`(见[搜索语法](./search))。

## 批量操作

图片列表勾选多张后可以:

| 操作 | 效果 |
| --- | --- |
| 移动到相册 | 批量移动,来源相册自动移出 |
| 设置可见性 | 批量切换公开 / 私有 |
| 删除 | 进入回收站,默认保留 7 天(见[隐私与回收站](./privacy-and-trash)) |

## 公开画廊

画廊是无需登录的公开页面(`/api/gallery`),瀑布流展示**公开**图片及其缩略图,不返回任何 EXIF。

在后台「系统设置 → 访客与画廊」里控制:

- **画廊开关**:整体开 / 关。关闭后画廊页面返回不可用,已分享的直链不受影响。
- **只展示公开相册的图**:开启后,公开但未归入公开相册的图片不再出现在画廊。

给相册开一个[随机图片链接](./random-links)也是对外分享的常用方式,两者互不影响。

## 和可见性的关系

图片的公开 / 私有决定它是否出现在画廊与公开直链中;相册本身没有公开属性。想让「整个相册对外可见」,通常的做法是:把相册内的图设为公开,或使用随机链接(随机链接对相册内所有图片生效,包含私有图,启用前界面会提示)。
