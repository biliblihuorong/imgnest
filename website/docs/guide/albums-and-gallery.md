# 相册管理

相册用来整理自己的图片。这一页只说明相册操作；全站访客能看到什么，由管理员单独配置。

## 相册

入口是登录后的「我的相册」（站内地址 `/albums`）。点击相册**封面或名称**进入详情；卡片上的「编辑」用于改相册资料，不是进入详情。

### 创建相册并放入图片

1. 在「我的相册」点「新建相册」，填写名称，按需填写简介、公开性和封面，再点「创建」。
2. 新图片：进入「上传图片」，在相册选择框选中这个相册后上传。
3. 已有图片：进入「我的图片」，勾选图片，在出现的批量操作栏选择目标相册，点「移动到相册」。
4. 回到「我的相册」，点击封面或名称，确认图片已经出现在相册详情里。

改名、简介、封面或公开性：在相册卡片点「编辑」，修改后点「保存」。删除：点卡片的「删除」并确认。删除相册不会删除图片，图片回到「未分组」。

相册详情标题栏的「随机图片链接」用于创建可匿名访问的随机图片地址，完整步骤见[随机图片链接](./random-links.md#从哪里打开)。

- 每个相册可以设置封面；相册详情页看到的永远是这个相册里的图，切换搜索词也不会越出范围。
- 上传时可以直接指定相册；已有图片用批量操作移动。
- 「未分组」是一个固定视图，代表不属于任何相册的图片，在搜索里对应 `album:unfiled`（见[搜索语法](./search.md)）。

## 批量操作

图片列表勾选多张后可以：

| 操作 | 效果 |
| --- | --- |
| 移动到相册 | 批量移动，来源相册自动移出 |
| 设置可见性 | 批量切换公开 / 私有 |
| 删除 | 进入回收站，默认保留 7 天（见[隐私与回收站](./privacy-and-trash.md)） |

## 相册公开性

相册和图片各有自己的公开 / 私有属性。把相册设为公开，不会把其中的私有图片一起公开；管理员开启「画廊仅展示公开相册」时，相册公开性才参与画廊筛选，见[访客与公开展示](./public-access.md#公开画廊)。

控制台的相册详情仍需要登录，相册设为公开不会自动生成无需登录的相册详情页。想用一个地址随机展示相册中的图片，可以创建[随机图片链接](./random-links.md)；该链接可能包含私有图片。
