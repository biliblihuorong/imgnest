# 上传与图片管理

这一页面向已经登录的使用者。管理员先配置存储、规则和用户组，普通用户只需要选择允许使用的规则并上传。

## 从哪里打开

登录后从导航进入「上传图片」（`/upload`）或「我的图片」（`/images`）。手机先点「打开导航」。

## 上传图片

1. 打开「上传图片」，拖拽、选择或粘贴图片。
2. 选择可用规则；需要整理时选择相册。
3. 决定图片是否公开。默认是私有，公开性控制它是否能进入画廊，不控制已分享直链的访问。
4. 开始上传，逐项查看成功或失败结果。失败项可以单独重试。

文件大小、格式、容量和频率受所属用户组限制；规则决定保存原图、WebP、缩略图以及可选的响应式版本。页面读出的单文件上限用于提前提示，服务端仍会校验。

## 复制和使用链接

上传完成后，在结果列表选择链接格式（URL、Markdown、HTML 或 BBCode）与图片版本（原图、WebP、缩略图），再复制对应结果。实际可用版本取决于规则；只保存 WebP 的规则没有单独的原图文件。

图片直链可用于博客、论坛和文档。需要让访问图片本身也经过身份验证的私密文件，不适合用当前的公开直链存储方式，详见[图片可见性与直链](./privacy-and-trash.md#图片可见性与直链)。

## 管理已有图片

- 「我的图片」只管理自己的图片；管理员的全站图片页可以管理所有用户的图片。
- 点击图片文件名打开详情；新版宽屏也可以点击图片下方的信息区，右侧会显示属性与 EXIF。点击缩略图用于大图预览。
- 复制已有图片链接：在电脑上右键点击图片卡片 →「原图 / WebP / 缩略图」→「复制 URL / Markdown / HTML / BBCode」。未生成的版本不可选。触屏浏览器若无法调出右键菜单，可在电脑端操作；上传完成时也可直接从上传结果复制。
- 重命名：同一个右键菜单 →「重命名」→ 保存，只改显示名称，不改变图片地址。
- 勾选多张图片后，列表出现批量操作栏，可以移动到相册、设为公开 / 私有或批量删除。
- [相册管理](./albums-and-gallery.md)负责整理，[搜索语法](./search.md)负责筛选，搜索条件可以随页面地址保存。
- 删除进入[回收站](./privacy-and-trash.md#回收站)，默认保留 7 天；入口是「我的图片」顶部的「回收站」标签，恢复与彻底删除也在这里操作。
