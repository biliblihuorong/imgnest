# 访客与公开展示

管理员在「站点管理 → 站点设置 → 访客与画廊」决定访客可以看什么、能否上传。**公共画廊、游客上传、开放注册是三个独立开关**，打开其中一个不会自动打开另外两个。

## 从哪里设置并检查结果

1. 管理员登录 →「站点管理 → 站点设置 → 访客与画廊」（`/admin/settings/access`）。
2. 修改「公共画廊」「画廊仅展示公开相册」或「游客上传」；使用「访客视角预览」检查候选数量和图片。
3. 点「保存设置」，看到保存成功提示后，再用未登录窗口打开站点首页 `/` 和公开画廊 `/gallery` 验证。预览不等于保存。

## 访客打开站点会看到什么

下表描述未登录用户打开站点根地址 `/` 时的行为：

| 公共画廊 | 游客上传 | 访客页面 |
| --- | --- | --- |
| 关 | 关 | 跳到登录页 `/login` |
| 开 | 关 | 公开首页 `/home`，展示最新 12 张公开图片；有完整画廊入口，上传需要登录 |
| 关 | 开 | 公开首页和游客上传区，不显示画廊 |
| 开 | 开 | 公开首页同时提供游客上传和公开图片展示 |

游客上传还需要有效的游客用户组。建议在设置页明确选择；兼容旧配置时，服务端也会尝试使用标记为游客的组。找不到有效组时按未开放处理。注册入口只在开放注册时出现。已登录用户访问 `/` 进入自己的控制台；直接访问 `/home` 时会看到进入控制台的入口。

## 公开画廊

完整画廊页面是 `/gallery`，数据接口是 `/api/gallery`，无需登录。展示范围包括全站用户已设为公开的有效图片，按上传时间从新到旧排列，**历史公开图片也会被列出**。开启画廊不会把私有图片自动改成公开。

- 私有图片、回收站图片和已停用账户的图片不会展示。
- 开启「画廊仅展示公开相册」时，图片和所属相册都必须公开；未归入相册的图片也被排除。仅把相册设为公开，不会自动公开其中的私有图片。
- 画廊展示图片名称和上传者显示名（没有显示名时用用户名），可以点击预览；接口不返回 EXIF、GPS、邮箱或上传 IP。
- 没有符合条件的图片时显示空态；请求失败时显示错误与重试按钮，不会被当成没有图片。

### 开启前预览

设置页的「访客视角预览」显示当前相册范围会公开展示的图片总数，并可展开查看最新 12 张。即使画廊尚未开启，管理员也能预览。

调整「仅展示公开相册」会重新计算预览。**预览不会保存设置、开启画廊或修改图片权限**；点击设置页的保存按钮才会应用开关。数量是查询时的结果，后续上传或权限变更可能改变它。

### 关闭以后

- 后续画廊请求返回空列表；直接访问 `/gallery` 显示「站点未开放公开画廊」。
- 若游客上传仍开启，公开首页保留上传区；两者都关闭时，新访客进入登录页。
- 图片不被删除，用户和管理员仍可管理它们。
- 已经分享的原图、WebP、云缩略图直链和相册随机链接不受画廊开关影响。已打开页面不会收到实时关闭推送，已加载的图片也不会自动撤回。

关于「私有」与直链的区别，以及如何删除或停用分享，见[隐私与回收站](./privacy-and-trash.md#图片可见性与直链)和[随机图片链接](./random-links.md)。

## 公开首页与游客上传

在「访客与画廊」打开游客上传并选好游客用户组。游客无需账号就能拖拽、选择或粘贴图片，上传后复制 URL、Markdown、HTML 或 BBCode。

- 单文件大小、格式、容量和可用规则取游客用户组的设置，见[用户与用户组](./users-and-groups.md)。限流按访客地址计算，与蓝空 v1 匿名上传共用计数。
- 游客不能选择相册，图片一律设为私有，不进入画廊。
- 游客上传后不能自行管理或删除图片；需要时由管理员处理。需要持续管理图片的使用者应注册并登录。
- 已登录用户从控制台上传，不再以游客身份上传。

## 搜索引擎与站点地图

同一页底部有「搜索引擎抓取」和「图片站点地图」两项，管的是本站域名下的 `/robots.txt` 与 `/sitemap.xml`，两者都由服务端按设置实时生成。

| 抓取模式 | robots.txt 内容 |
| --- | --- |
| 全部禁止（默认） | `Disallow: /`，整站不让抓 |
| 只开放首页与画廊 | 只允许 `/`、`/home`、`/gallery`、前端资源 `/assets/` 和本机存储图片 `/i/`、`/t/`；后台、登录页、API、随机图链接一律禁止 |
| 自定义 | 原样输出你填写的内容（最多 8 KB）；留空等同全部禁止 |

- robots.txt 只能约束本站域名。放在 S3、B2 等外部存储域名下的图片要在存储那边自己设置（例如防盗链或桶策略）。
- 「只开放首页与画廊」会放行 `/i/`。私有图片的直链本来就能匿名打开，被别处引用后也可能被抓取；不想这样就保持「全部禁止」。
- 无论哪种模式，控制台、登录页、`/api/` 和随机图链接的响应都带 `X-Robots-Tag: noindex`，不会进入搜索结果。

打开「图片站点地图」后，`/sitemap.xml` 列出首页和画廊，并在画廊下附上最新的 1000 张公开图片（Google 图片站点地图格式），范围与画廊一致，同样遵守「仅展示公开相册」。它只在画廊开启、抓取模式不是「全部禁止」时提供，否则返回 404。列表最多每 10 分钟刷新一次，不含 EXIF 和上传者信息。「只开放首页与画廊」模式会自动在 robots.txt 里写上 `Sitemap:` 行；自定义模式请自己加一行 `Sitemap: https://你的域名/sitemap.xml`。

## 常见情况

| 现象 | 先检查 |
| --- | --- |
| 打开站点只看到登录页 | 画廊和有效的游客上传是否都关闭 |
| 画廊开启了却没有图片 | 图片是否公开、是否在回收站、账户是否停用，以及是否限制为公开相册 |
| 打开游客上传开关仍无法上传 | 游客用户组、可用规则、存储状态与限额 |
| 关闭画廊后图片链接仍能打开 | 这是直链的既定行为；关闭画廊只停止公共列表展示 |
