# ImgNest 是什么

ImgNest 是一个自托管图床，后端用 Go，界面用 Vue 3。它的目标是替代蓝空图床（Lsky Pro）社区版：数据放在你自己的服务器和存储桶里，原有的上传客户端不用换。

## 能做什么

- **多用户、多存储、多规则**：每个用户组可以绑定不同的存储和上传规则，存储支持本机磁盘和 S3 兼容服务。
- **原图和 WebP 各存一份**：上传时同步转出 WebP 和缩略图，响应返回时几个链接都已经可以访问。
- **兼容蓝空 v1 API**：PicGo、uPic、Typora 等客户端改一下接口地址就能继续用。
- **保护隐私**：完整 EXIF 只存在本地数据库，放到云端的原图会被无损抹掉 GPS、序列号和作者信息。
- **删除可恢复**：删除先进回收站，默认保留 7 天，原链接立刻失效。
- **两套界面**：经典布局和新版布局可以在运行时切换，都支持深色模式和中英文。

## 当前状态

::: warning 还没有正式版本
ImgNest 仍在开发中，尚未发布 v1.0.0，也还没有提供生产镜像。目前通过仓库里的 Docker 开发镜像运行，已验证的平台是 Linux amd64。
:::

已经实现的部分：

| 模块 | 内容 |
| --- | --- |
| 账户 | 用户、用户组、Token、登录限流、验证码 |
| 存储 | 本机存储、S3 兼容存储、上传规则与路径模板 |
| 图片处理 | WebP 转换、双缩略图、EXIF 归档与无损脱敏 |
| 管理 | 回收站、相册、公开画廊、管理后台 |
| 兼容 | 蓝空 v1 API、蓝空数据迁移 |

## 技术构成

| 部分 | 选择 |
| --- | --- |
| 语言 | Go 1.27 |
| 图片处理 | libvips 8.18，通过 vipsgen 调用 |
| 数据库 | SQLite 或 PostgreSQL |
| HTTP | Gin |
| 界面 | Vue 3、Vite、TypeScript、Naive UI |
| 部署形态 | 界面打包后嵌进 Go 二进制，一个进程提供全部功能 |
