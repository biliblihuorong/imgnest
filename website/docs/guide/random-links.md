# 随机图片链接

一个固定地址，每次访问随机跳转到相册内一张图片的直链（`307` 重定向），可用于博客背景、README 配图或随机壁纸。

## 从哪里打开

**登录 → 我的相册 → 点击相册封面或名称 → 详情页标题栏的「随机图片链接」按钮。**

「我的相册」的站内地址是 `/albums`。随机链接按相册创建，入口在进入相册后的标题栏，不在相册卡片的「编辑」弹窗里。手机上先点「打开导航」进入「我的相册」；进入相册后，标题栏按钮可能换行显示。

## 创建并复制链接

1. 在「我的相册」找到要分享的相册，点击封面或名称进入。
2. 点击标题栏的「随机图片链接」，打开管理弹窗。
3. 第一次使用时点「启用随机链接」。阅读私有图片也会被匿名访问的提示，再点「确认启用」。
4. 弹窗出现地址输入框和「已启用」状态，点击旁边的「复制链接」。复制失败时可以在输入框手动全选复制。
5. 把地址粘贴到未登录的浏览器窗口打开，检查能否显示相册图片，再粘贴到博客或其他需要的位置。

::: warning 相册里的私有图片也会参与
创建随机链接是相册所有者对整个相册的分享授权。相册无需设为公开，管理员也无需开启公共画廊；相册内所有可用图片都可能被抽中，包括私有图片。回收站中的图片不参与。
:::

### 还没有相册或相册是空的

先在「我的相册」点「新建相册」，填写名称并点「创建」。然后在「上传图片」选择这个相册上传；已有图片可在「我的图片」勾选后用「移动到相册」移入。详见[相册管理](./albums-and-gallery.md#创建相册并放入图片)。空相册可以创建链接，但访问时返回 404。

## 在博客或 README 中使用

复制到的地址类似下面这样，由系统自动生成，不要自己填写 `uid` 和 `token`：

```text
https://img.example.com/random/{uid}/{token}
```

把示例地址整体换成自己复制的地址：

```markdown
![随机图片](https://img.example.com/random/你的公开ID/你的链接令牌)
```

```html
<img src="https://img.example.com/random/你的公开ID/你的链接令牌" alt="随机图片" />
```

默认优先显示 WebP；需要原图时，在复制的地址末尾加 `?format=original`。浏览器或博客平台可能缓存已显示的图片，因此刷新文章不保证每次都换成不同的图，随机抽取本身也可能再次选中同一张。

## 停用、重置和删除

回到同一个相册，再次打开「随机图片链接」弹窗：

| 我想做什么 | 在弹窗里怎么操作 | 对已有链接的影响 |
| --- | --- | --- |
| 暂停使用，之后恢复 | 关闭启用开关；需要时重新打开 | 停用期间返回 404，重新启用继续用原地址 |
| 换一个地址 | 点「重置链接」并确认 | 旧地址立即失效，重新复制新地址并替换博客里的引用 |
| 移除这个分享入口 | 点「删除链接」并确认 | 当前地址立即失效；以后再启用会生成新地址 |

这些操作只控制随机链接，不会撤销已经被访问者拿到的图片直链。要让源站图片地址失效，需要删除图片，见[隐私与回收站](./privacy-and-trash.md#图片可见性与直链)。

## 链接打不开时检查什么

- **显示链接加载失败**：在管理弹窗点「重试」，加载成功后再操作。
- **访问地址返回 404**：确认相册至少有一张未删除的图片、链接处于「已启用」、账号未停用，且复制的是最新完整地址。对外统一返回 404，不显示具体原因。
- **返回 400**：检查查询参数，只支持 `format=original`；去掉其他 `format` 值后重试。
- **返回 429**：访问过于频繁，稍后再试；限制为每客户端地址每分钟 600 次。
- **跳转后图片打不开**：检查图片存储的访问地址与对象是否正常。随机链接只负责选择和跳转，不会代理存储里的图片。

## 地址与缓存细节

- `uid` 是所有者的 10 位随机公开 ID，`token` 是 24 位随机串，均由系统生成。知道链接的人可以匿名使用，请按分享地址保管。
- 默认优先 WebP，缺少时回退原图；`?format=original` 优先原图，缺少时回退 WebP。
- 随机跳转响应带 `Cache-Control: no-store`，不返回图片元数据与 EXIF；图片文件本身的脱敏由上传规则决定。
- 候选图片列表在服务端缓存 60 秒，每相册最多 5000 张，超出后随机采样。相册内容变化会主动失效缓存；多实例未接共享缓存时，其他实例最多延迟 60 秒，已删除图片的源站地址已经失效。
- 图片直链由存储的 `base_url` 拼出。修改存储访问地址会改变跳转目标；相册随机链接本身不变。
