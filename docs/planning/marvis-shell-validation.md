## 环境

- Docker Desktop Linux 引擎，`deploy/compose.dev.yaml` 的 `dev` 容器，Node 24.21.0、pnpm 12.9.1。本机 Node 22 不满足 `engines`，所有前端命令都在容器内执行。

## 浏览器验收

方式：`go run -tags vben ./cmd/imgnest serve` 提供生产构建，本机 `http://localhost:18080`，SQLite 新库，一个管理员账号，经 `/api/v1/upload` 上传 5 张 PNG。用应用内置浏览器在 1440×900 与 375×812 两种视口下操作。内置浏览器面板不在前台时不绘制画面，CSS 过渡会停在起始帧，所以多数检查读取的是 DOM 与计算样式，只有三处拿到了截图（概览页、用户管理页、图片页加设置弹窗）。

通过的项目：

1. 新浏览器首次登录后是 Marvis 外壳；`localStorage["imgnest-shell"]` 写入 `marvis`；强调色与圆角为 Marvis 默认值。
2. 设置 → 外观 → 经典布局：切到 Vben 布局，不刷新、不掉登录，当前页面和列表数据保留。经典布局用户菜单里的「切换到新版布局」可切回。
3. 自选强调色后切换布局，强调色保持；未自选的圆角跟随布局默认值。
4. 自选强调色和圆角后在深色模式下切换布局，Naive UI 卡片底色与新布局的 `--card` 一致（审查发现的问题，修复后复验通过）。
5. 「我的图片」宽屏：右侧详情面板显示所选图片的元数据与 EXIF 区块，对应卡片高亮。
6. 右键图片：菜单项为 原图 / WebP / 缩略图 / 属性 / 设为公开 / 删除，与改动前一致。
7. 点击缩略图打开灯箱。
8. `Ctrl K`：打开检索，焦点在输入框；输入 `format:png` 回车后跳到 `/images?qv=1&q=format:png…`，统一搜索输入框同步为该条件并返回 5 张结果。
9. 设置弹窗：深浅色、强调色、圆角、紧凑侧栏（侧栏 244px → 68px）、恢复默认、语言切换按钮都在，账号页显示资料表单和修改密码表单。
10. 侧栏「新建相册」：弹出原相册表单，创建后跳到 `/albums/1`，侧栏立即出现该相册。
11. 375px：侧栏为抽屉，菜单按钮打开、导航后自动收起；没有详情面板，点文件名打开详情抽屉；页面无横向滚动。
12. 管理后台「用户管理」页在 Marvis 外壳下表格与分页显示正常，无横向溢出。
13. 已缓存旧偏好的浏览器重新加载后，版权相关偏好被清空且 `settingShow` 为 `false`。
14. 全程浏览器控制台无报错。

没有在浏览器里验证的项目：

- 右键菜单二级项的实际复制结果、灯箱的左右翻页：只由组件测试覆盖（改动前的用例未改且通过，另加了面板模式下的同一组断言）。
- 上传页结果行随格式切换更新：内置浏览器不能选择本地文件上传，只由组件测试覆盖。
- 语言切换后的英文界面、匿名访问 `/gallery` 时的设置入口：只由组件测试覆盖。
- 布局 chunk 加载失败后的回退：只由组件测试覆盖。
- 管理后台其余五个页面、回收站、Token 页、上传页的观感：没有逐页截图。

## 独立审查

全部任务完成后由一个独立审查者通读整个分支（`1744ee7..HEAD`）。结论：没有严重问题，现有交互逻辑未被改动；提出 6 条重要问题，已处理：

| 问题 | 处理 |
| --- | --- |
| 布局 chunk 加载失败后再切回该布局会白屏，且失败会改写用户保存的布局 | 已修复：失败只影响当前会话的渲染，不改保存值；再次选择时重新加载；两套都失败时显示重新加载提示 |
| Marvis 外壳里没有语言切换；匿名访客没有设置入口 | 已修复：外观面板加语言切换；匿名访客可打开设置（只有外观） |
| 详情面板里的图片被删除或翻页后仍然显示 | 已修复：面板跟随列表，图片不在列表里即清空 |
| 弹窗的 Esc / Tab 只在焦点位于弹窗内时生效；`Ctrl K` 会在别的弹窗之上打开 | 已修复：改为在 document 上监听；已有其他模态层时忽略快捷键 |
| 自选了强调色和圆角后切换布局，Naive UI 底色不更新 | 已修复并在浏览器复验 |
| 缺少本验收记录 | 即本文 |

未处理、留待决定的次要问题：

- 「用户自选」靠「是否等于另一套布局的默认值」判断，所以在 Marvis 下特意选了经典蓝或中圆角，切到经典再切回会被改回 Marvis 默认值。
- 窄屏抽屉侧栏收起时其链接仍在 Tab 顺序里；打开时没有 Esc 关闭和焦点限制。
- 设置弹窗的分类标签没有方向键切换和 `aria-controls`；关闭时未保存的显示名修改不提示。
- 检索弹窗的方向键选中项没有对读屏软件播报。
- 强调色按钮的读屏名称是「强调色 N」，没有颜色名。
- 侧栏相册列表只在离开 `/albums` 时刷新，在该页改名或删除后要离开页面才更新。
- 收起侧栏会卸载相册分组，正在填写的新建相册表单会被关闭。
- 详情面板宽 320px（计划写的是 308px）；检索弹窗提交时每页条数固定为 20。
- `useNarrowViewport.ts` 放在 `layout/marvis/` 下却被图片库引用，位置应更中立。
