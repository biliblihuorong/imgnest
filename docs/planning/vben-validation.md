## 两种前端与体积

make release / make release-legacy选择旧前端，输出bin/imgnest-legacy；make release-vben选择新版，输出bin/imgnest-vben。两边独立安装/构建，旧版不需要Vben依赖。完整构建步骤见docs/development.md和docs/planning/dual-frontend-build.md。

实测静态产物：legacy dist 1,160,574字节，Vben dist 2,776,917字节；新版最大bootstrap chunk约1,189.33kB，gzip约339.29kB，构建仍提示大于500kB。没有通过调高阈值隐藏提示。源包不含node_modules、数据库或本机编译的二进制；实际二进制验证单独记录。

验证码关闭时两版可以选用同一后端。启用后，未改动的旧版登录页不会发送验证码，不能无条件回退；必须事先确定旧版适配或明确的管理员/操作员停用策略，不自动降低保护。v1密码换Token入口的兼容策略未改变，不能声称验证码覆盖了全部认证入口。详见docs/captcha.md。
